# 명예의 결투 초기 진형: 사용자 캡처 학습

## 확인된 선택지
1. 성상의 조각: 페르세우스(레오프론/전사/물리/1), 오리안(레오프론/전사/마법/1), 틸로아(와일더스/전사/물리/1). 표시60.
2. 불멸의 불꽃: 귀네스(레오프론/사수/물리/8), 퀸(와일더스/서포터/마법/5), 발리카(그레이브본/전사/물리/1). 표시60.
3. 마이다스의 재물: 발리카, 카렌(그레이브본/탱커/물리/1), 스모키와 미르키(트라이브/서포터/마법/8). 표시60.
4. 랜덤: 내용 숨김, 표시70. 확률 및 표시 재화의 용도 미확인.

8명 모두 상세창에서 에픽을 확인. 명예의 결투 제공 등급이며 개인 계정 보유 등급과 별도. 계정 미보유 제한을 모드 제공 영웅에 적용하지 않는다. 초기 영웅이 체험 카드라는 증거는 없다. 잠긴 전용 스킬을 기대 성능에 더하지 않는다.

46 잠금: 레전드 장비1개 선택.

## 조건부 추천
3번 마이다스의 재물 우선: 즉시 공방 효과 + 탱커 카렌 + 치료 스모키 + 전사 발리카. 검증된 승률이나 클리어 보장 아님. 초기 체험 보너스와24/46 효과 제외.
다음 전장에서는 카렌 전방, 발리카 측면 전방, 스모키 뒤쪽 치료 범위 안을 시작 개념으로 삼되 실제 칸/추가2명은 상점 및 배치 화면 확인 후 결정.
2번은 궁극기4회 도달 이후 효과,1번은 아군 레오프론 사망 선행. 상세 스킬 전체/적/후속 상점이 없으므로 절대 성능 순위 아님.
