# 변형된 예티 학습 원장

## 범위와 고정 정책
사용자 모드: 배틀 모드 > 일반 콘텐츠 > 꿈의 세계. 초기 보스270에서 노멀 II 보스340으로 상승. 화면 영웅402, 파진술+18 장착은 관찰 사실이다. 비시즌이라는 명칭만으로 보이는 장착을 부정하지 않되, 시즌 효과 실제 적용은 별도 확인한다. 망령의 소굴505M/98%, 번창 파티121M/89.6%, 미궁 기록과 혼합하지 않는다.
사용자 정정 > 캡처 > OCR/초상 > 추론. 추천마다 개별 사용자 초상화·이름·확인 등급·진영·클래스 표시. 기존 개별 초상을 찾기 전에 합성 명단이나 '상단 두 번째 얼굴'로 대체하지 않는다. 등급을 테두리로 추론하지 않는다.
교체는 보유 영웅 중 확인된 등급이 기존 영웅과 같거나 높은 경우만 허용한다. 낮거나 미확인 등급은 후보에서 제외한다. 이는 사용자의 고정 제약이며 게임 전체의 성능 법칙은 아니다. 한 번에 하나만 변경하고 생존과 피해를 분리한다. 계속 영상 제출을 요구하지 않고 배치/결과/통계와 첫 사망 영웅·시점으로 조정한다. 사망 원인 스킬은 결과만으로 단정하지 않는다.

## 최신 결과와 판단
초기 난이도 413M/100%. 노멀 II 순서: 549M/41.9%, 550M/42.0%, 601M/45.9%, 700M/53.4%, 687M/52.4%, 704M/53.7%, 558M/42.6%.
최고 관측은 울머스·세미라·아로라·퀸·솔리스 704M/53.7%, 사용자 전원 생존 확인. 700M 대비 +4M은 단일 시도 차이이므로 안정적 우월성 증명은 아니다. 100% 클리어 아님.
에디는 549/550M에서 58초 사망, 에이론은 687M에서60초 사망, 팔라모르는 마지막558M에서60초 사망. 시간 표기는 사용자의 보고이며 경과/잔여 해석을 원본 없이 자동 변환하지 않는다. 601/700/704M은 사용자 사망 없음 확인. 마지막 다른 네 영웅 생존 여부는 미확인.
마지막 탱커 울머스→동일 레전드 팔라모르 교체는 -146M, -11.1%p 퇴보. 동일 등급만으로 탱킹 역할 대체가 보장되지 않는다. 현재 계정의 관측에서는 울머스 전열 유지가 더 안정적이었다. 남은 횟수0은 6회 보고 이후 추가 숨은 도전이 없다는 조건의 추정이며 현재 횟수 확정값이 아니다.

## 보스 스킬: 사용자 캡처 우선
얼음 감옥: 시작 최전방 대상6초 행동 불가, 제어 면역/무적 무시. 과거 웹 가이드의 최고 피해 영웅20초 감금 설명을 적용하지 않는다.
고요한 눈보라: 전투 시작10/40/70초 후25초 전원 침묵, 초당 공격력60%; 300/301/302레벨 해금80/100/120%. 340보스에270캡처의60%를 그대로 확정하지 않는다. 침묵이 무적 무시라는 설명을 모든 피해 무적 무시로 확대하지 않는다.
스노우 데버: 단일150% 고정 피해,8초간 초당30% 고정 출혈. 눈덩이 투척: 대상/주변1칸180%,8초 공격력20%감소. 한기의 숨결: 전방1칸 부채꼴120%씩3회.

## 영웅 해금과 외부 자료의 한계
아로라 신화+, 전용+10, +15 단기 불가. +15의 방어 무시를 현재 효과에 합산하지 않는다. 상세 사용자 스킬은 번창 파티 원장 보존. 악몽의 적 공격력+2%를 감소로 뒤집지 않는다. 솔리스 신화, 퀸 레전드의 상세 사용자 스킬도 같은 원장 우선.
팔라모르 레전드: 인접/뒤 아군 서약 공격력 지원 설명, 보호막 및 단일 피해 가능. 신화+ 추가 고정 피해75% 효과는 잠금. 침묵 중 지원 가동률은 미확인. 700M에서142M 피해, 탱커 대체558M에서27.154M으로 하락.
세미라 신화: 궁극기 유령·HP 소모/회복 구조. 신화+ 보호막, 전용+10 효과는 잠금. 유령이 아로라가 인식하는 소환물인지는 미확인. 704M에서204M, 마지막558M에서151M. 솔리스 웹 설명과 사용자 캡처 수치가 다르면 사용자 캡처를 우선한다.
에디 레전드: 신화+ 처형/전용+10 시작 에너지 효과 미해금. 다미안 에픽+: 신화+ 급속40 미해금. 에이론 에픽/레인저: 시작 궁극기 및 챔피언+ 추가 방어 감소 미해금. 퀸60%와 에이론40% 방어 감소를 단순 합산하여 방어0으로 보장하지 않는다.

## 보존과 적용 경계
전체 세션·첨부 원본은 PC 보관, 학습 화면에는 정정된 자료/전체 대화 텍스트/사용자 초상화 포함. 원문 속 철회된 추천은 역사 자료이며 최신 정책보다 우선하지 않는다. 현재 앱에는 새 자동 추천 엔진이나 게임 조작을 추가하지 않는다. 자료 반영과 자동 추천 로직 집행은 다른 기능이다. 초상화 소스 누락은 명세에 표시하며 임의 이미지로 대체하지 않는다.
