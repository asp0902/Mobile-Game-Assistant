## 정답 기록 원칙

- 게임 viewport 내부 좌표만 기록한다. 시스템 UI/창 테두리는 기준점으로 쓰지 않는다.
- 영웅 위치는 sprite 중심이 아니라 발밑 anchor를 가장 가까운 hex tile에 연결한다.
- 사용자 정정과 상세 팝업 텍스트가 자동 인식보다 우선한다.
- 동적 효과(예: 퀸의 마법진)는 고정 타일 정답으로 저장하지 않는다.

## #16 완료에 필요한 추가 승인 자료

- 영웅 관리, 영웅 판매, 전투 결과, 영웅/장비 상세 팝업의 대표 캡처와 정답
- 16:9, 19.5:9, 20:9 및 시스템 UI·Game Booster·플로팅 아이콘 가림 사례
- 발렌/페르세우스, 발렌/귀네스, 레전드 체험 카드, 최대등급, 판매가 회귀 정답

이 목록이 채워지고 사용자가 정답을 승인하면 #16을 완료한다.
