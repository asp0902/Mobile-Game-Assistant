AFK 영웅 이미지 인식 패키지 — 2026-08-20

목적
- 이번 대화에서 사용자가 직접 제공한 영웅 상세 캡처를 Codex로 전달할 때,
  단순 텍스트가 아니라 초상화 ↔ 이름 ↔ 진영/직업/공격타입/사거리의 정답표를 함께 보존한다.
- 이 패키지는 모델 가중치를 실제로 재학습하는 파일이 아니라, Codex가 프로젝트 컨텍스트에서
  이미지 식별을 재현할 수 있도록 제공하는 'ground-truth reference dataset'이다.

구성
- source_full/: 원본 영웅 상세 캡처 24장. 이름이 화면에 직접 표시되어 있어 최우선 정답 근거다.
- portrait_card/: 각 상세 팝업 왼쪽 카드 초상화의 표준화 crop. 작은 카드/로스터 식별에 사용.
- popup_panel/: 이름+초상화+역할 정보가 함께 보이는 crop. 라벨 검증용.
- metadata/hero_manifest.csv/json/jsonl: 파일 ↔ 영웅 라벨 매핑.
- metadata/이계의_미궁_Codex_증분_학습데이터_2026-08-20.txt: 런/전투/유물/낙인 학습 컨텍스트.
- reference_battle/: 라벨링 직후의 편성/배치 화면. 카드 초상화와 필드 캐릭터 연결 참고용.
- hero_contact_sheet.jpg: 24영웅 한눈 검증용.

Codex 사용 규칙
1. source_full과 popup_panel에서 화면에 직접 적힌 이름을 ground truth로 취급한다.
2. 이후 스크린샷에서 작은 로스터 카드가 나오면 portrait_card와 비교한다.
3. 공격력/전투력(captured_power)은 당시 캡처값이므로 영구 능력치로 저장하지 않는다.
4. 얼굴이 애매하면 추측하지 말고 unknown/unverified로 유지한다.
5. 새 사용자 캡처가 기존 라벨과 충돌하면 최신 직접 캡처를 우선한다.
6. 이 자료는 이미지 자체를 포함하므로 TXT 단독 전달보다 초상화-캐릭터 대응 보존력이 높다.
7. 단, Codex가 이 파일을 받는 것만으로 모델 자체가 fine-tuning 되는 것은 아니다. 프로젝트 컨텍스트/참조 데이터로 사용해야 한다.
