# 추천 엔진 요구사항

기존 Rule Engine 패턴을 재사용하고 동일 입력에서 동일 결과를 반환하는 결정론적 구현으로 만든다.

선택지가 여러 개일 때 다음 상태를 사용한다.

- `CHOOSE`
- `CONSIDER`
- `SKIP`

효과가 불명확하거나 화면 신뢰도가 낮으면 선택 상태를 억지로 부여하지 말고 `확인 필요`로 표시한다.

추천 이유에는 가능한 범위에서 다음 근거를 포함한다.

- 현재 출전 조합
- 탱커·딜러·힐러 역할 균형
- 남은 영웅과 사망 영웅
- 현재 HP
- 영웅별 실제 피해·회복·피격
- 유물과 낙인 시너
